# ポケットレジェンド 碧の章

ポケモンシリーズのゲーム体験(ストーリー・戦闘システム・音楽・UX/UI)を追求した、
ブラウザで動くオリジナルのモンスター収集RPGです。
モンスター・楽曲・ドット絵はすべてオリジナル(手続き生成含む)で、外部アセットに依存しません。

## あそびかた

`index.html` をブラウザで開くだけで遊べます(ビルド不要・オフライン動作)。

| 操作 | キーボード | 画面ボタン |
|---|---|---|
| 移動 | 矢印キー / WASD | 十字キー |
| けってい | Z / Space | A |
| キャンセル | X / Esc | B |
| メニュー | Enter | START |

## ゲーム内容

- **ストーリー**: カエデ博士から御三家(くさ/ほのお/みず)を選び、ライバル・レンと競いながら
  **8つのジムバッジ**(みず/くさ/ほのお/ひこう/でんき/ゴースト/いわ/ノーマル)を集め、
  悪の組織ダークスター団の野望を阻止し、チャンピオンを目指す。殿堂入り後はチャンピオン再戦が可能。
- **戦闘システム**: ポケモン式ターン制。わざ(威力/命中/PP)、8タイプ相性、急所、
  STAB、状態異常(どく/まひ/やけど/ねむり)、能力ランク、交代、捕獲(ボール演出つき)、
  経験値・レベルアップ・わざ習得・しんか。踏み込み・タイプ色ヒットバースト・
  画面シェイク(こうかばつぐん時)などの戦闘演出つき。
- **世界**: コダチタウンから8都市+ルート1〜8+洞窟+ヴィクトリーロード+リーグ。
  草むらエンカウント、視線で勝負を挑むトレーナー、モンスターセンター、ショップ、ずかん。
- **音楽**: Web Audio API によるチップチューン(タイトル/まち/ルート/洞窟/戦闘/ジム/
  しんか/エンディング等をオリジナル作曲)+効果音・鳴き声。
- **UI/UX**: GB/GBA風の携帯機シェル、タイプライター式メッセージ、HP/EXPバーのアニメ、
  マップ名バナー、レポート(セーブ)機能(localStorage)。

node --check monster-art.js data.js game.js

## 刷新の進捗(CLAUDE_RENEWAL_BRIEF.md 対応)

基盤スタッフを実装済み:

- **完全オフライン**: Google Fonts への外部接続を廃止し、OS 同梱の丸/角ゴシックへフォールバック。
- **セーブデータ v2**: `fakemon_save_v2` に保存。旧 `fakemon_save_v1` を自動でマイグレーション。
  欠損・破損セーブでも起動不能にならないよう正規化(不正な現在地は回復地点へ退避)。
- **ボックス機能**: モンスターセンターに「ボックス」端末。手持ち⇔ボックスの預け／引き出し／一覧・詳細。
- **通行ゲートの共通化**: 出入口ごとの `requirements` を `GameData.meetsRequirements()` で共通判定。
  ヴィクトリーロードは全 8 バッジ判定へ修正。ミナモ→ルート2 を NPC 依存でないエッジ条件化(迂回不可)。
- **マップ検証**: `tests/map-validate.cjs` で接続・歩行・到達性を検査(`rows` 共有マップは固有化対象として警告)。

後続(地域・物語の本体刷新)は `CLAUDE_RENEWAL_BRIEF.md` の実装順に沿って進行:
固有マップ4地域＋中央遺構、環核試練、サブクエスト8件、旅記録／マップUI、分岐エンディング。
