# ポケットレジェンド 碧環の旅

自然循環をささえる古代装置「碧環(へきかん)」が弱まった **セイリュウ地方** を舞台に、
守護獣と信頼を結び、失われた4つの環核を再接続する ―― オリジナルのモンスター共生RPG。
モンスター・楽曲・ドット絵はすべてコード生成で、外部アセットに一切依存しません(完全オフライン)。

## あそびかた

`index.html` をブラウザで開くだけで遊べます(ビルド不要・オフライン動作)。

| 操作 | キーボード | 画面ボタン |
|---|---|---|
| 移動 | 矢印キー / WASD | 十字キー |
| けってい・はなす | Z / Space | A |
| キャンセル | X / Esc | B |
| メニュー(ずかん/モンスター/バッグ/レポート) | Enter | START |

## 物語と世界(碧環の旅)

主人公は「選ばれた特別な少年」ではなく、地域の異変を記録する **若き巡環士候補**。
モンスターを倒して支配するのではなく、各地の **守護獣と信頼を築き** 環核を取り戻す。
ライバル **レン** は単純な悪役ではなく「人が装置を制御すべき」という合理主義者で、
主人公の「生態系に選択を委ねる」方針と対立する。

**非線形ワールド(一本道を廃止)** ― 中央拠点コダチから複数地域を任意の順で攻略:

```
コダチ拠点 ─┬─ 碧樹圏(森) ─┐
            └─ 潮環圏(水) ─┴→ 中央遺構 ─┬─ 火脈圏(炎/岩) ─┐
                                          └─ 雷霧圏(電/飛) ─┴→ 碧環中枢(結末)
```

- **環核試練**(8ジムを廃止し4地域に統合): 各地の守護獣に挑み環核を得る。2環核で中央遺構、
  4環核＋レンとの決着で碧環中枢が開く(**早期侵入不可**)。
- **能力ゲート**: フィールド能力は種族ではなく **タイプ** で判定(複数解決)。ほのお=倒木、
  みず=水門、いわ/みず=岩、ひこう/でんき=崖。奥に **任意エリアと隠し宝**(再訪の理由)。
- **サブクエスト9件**: 追跡/収集/選択/救助/環境変化を混ぜ、選択は結末スコアに反映。
- **3方針の分岐エンディング**: 行動履歴から **完全復旧 / 自然循環 / 分散管理** を導出。
- **戦闘**: ポケモン式ターン制(わざPP/8タイプ相性/急所/状態異常/交代/捕獲/経験値/しんか、
  踏み込み・タイプ色ヒット・画面シェイク演出)。**モンスターは28種を32×32骨格別に描画**。
- **音楽**: Web Audio チップチューン。**ボックス**(センターで手持ち⇔預り)、レポート(セーブv2)。

## 開発時の確認

```bash
node --check world-maps.js data.js story.js game.js
node tests/monster-art-smoke.cjs   # 28種の前面/背面スプライト生成
node tests/map-validate.cjs        # 出入口接続・歩行可能性・到達性・行幅・rows一意(共有は失敗)
node tests/world-graph.cjs         # 世界グラフ・地域解放・早期侵入防止・エンディング
node tests/progression.cjs         # 起点/遺構/中枢ゲート・能力ゲート・試練4種・サブクエ・結末・クリア後
node tests/ui-tap-targets.cjs      # スマホ操作ボタンの最小タップ領域44px・画面スケール外配置
```

セーブは `fakemon_save_v2`(旧 v1 は自動移行)。破損セーブでも起動可能。

## 実装状況(CLAUDE_RENEWAL_BRIEF.md 対応)

**実装済み**

- 完全オフライン(外部フォント廃止)／セーブ v2＋v1 自動移行＋破損耐性／ボックス端末。
- 非線形ワールド(拠点＋4地域＋中央遺構＋中枢を **全21マップ固有配列**、`rows` 共有なし)。
- 地域解放を `requirements` で共通判定(2環核で遺構・4環核＋レン決着で中枢・**早期侵入不可**)。
- 能力ゲート(**タイプ由来・複数解決**、扉は固形タイル上に配置=素通り防止)＋任意エリア。
- 横断路 碧樹↔潮環・火脈↔雷霧(循環路)。
- 環核試練=**地域固有パズルを解く→守護獣戦**(順序/水位/トグルの3型式)。守護獣勝利で環核。
- サブクエスト9件(**8件は 受注→現地の目標→報告 の多段**、1件は選択)。選択・救助等は結末スコアに反映。
- 灰星局イベント(強制起動の阻止＝自然寄り／救助＝分散寄り、フラグと台詞)。
- 進行度スケーリング `scaledLevel` を **野生・トレーナー・守護獣に適用**。
- 旅記録(主目標・進行中の任意目標・環核・灰星局)。地図ビューUI(現在地/未解放を色分け)。3方針の分岐エンディング。
- **地域クリア反応**: 各地域の環核を戻すと拠点・現地NPCの台詞と世界描写が変化(`variants`)。
- 試練の **固有パズル(3型式)**: 碧樹/雷霧=順序、潮環=水位、火脈=トグル(ライツアウト)。誤操作でリセット/未達。
- 灰星局アーク: 現地の強制起動阻止／救助／中央遺構の対決に加え、**本部長ゲンドウとの最終決戦**(碧環中枢)。
  アークを進めた場合、ゲンドウを退けるまで **最終決定に進めない**。結末に反映。
- 敗北ペナルティは所持金半減→**固定額(最大500)**。
- **クリア後要素**: 環核を戻すと 各地域に **希少種**(森竜/雨蛇/導き火/雷鳥)が出現。守護獣は **再戦**(強化個体)可能。未解決クエストは継続。
- **スマホUI**: 操作パッドは 画面スケールの外に置き、**最小タップ領域44px**を確保(縮小で潰れない)。せまい画面/横持ちにも対応。
