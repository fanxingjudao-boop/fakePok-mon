# ユーザー素材の置き場所(元画像)

生成した画像を、プロンプト集の名前(`mon_fire1.png` など)でここに置きます。
置き場所は `mon/` と `char/` のどちらでも構いません(名前で探します)。

ここの画像はそのままでは使いません。背景を抜いて縮小した版を作り、それをゲームに入れます。

1. 背景除去ツールを入れる(初回だけ。約760MB。モデル同梱でオフライン動作):
   `npm i --no-save @imgly/background-removal-node@1.4.5`
2. `npm run art:cutout` を実行する(変わった画像だけ処理。全部作り直すなら `-- --all`)。
   → `src/assets/cutout/<名前>.webp` ができる(透過・余白カット・長辺640px)
3. `npm run art:sheet` → `test-results/art-sheet.jpg` で仕上がりを確認する。
4. 戦闘で使う絵は `src/data/art.ts` で `import` する(使う絵だけがページに入る)。

## うまく抜けないとき

`src/assets/cutout.config.json` で、画像ごとに方法を変えられます。

| 方法 | 向いている絵 |
|---|---|
| `ml`(既定) | ほとんどの絵。AIで被写体を切り抜く |
| `key` | 白い背景に白っぽい体の絵(AIが体まで背景と見なす場合)。外周から背景色を塗りつぶして抜く |
| `vignette` | 体が背景と一体の絵(森そのものの守護獣など)。元の絵を残し、周囲をぼかして溶け込ませる |

## 次に絵を作るときのコツ

- **背景は無地の白**にすると、きれいに抜けます。背景付きの絵は抜けにくくなります。
- 生成した縦長(832×1248)のままで大丈夫です。余白は自動で切り詰めます。
