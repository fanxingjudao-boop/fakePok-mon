# 碧環の旅 共鳴バトル(試作版 Phase 0)

「ポケットレジェンド 碧環の旅」を本格的なRPGとして作り直すための、**戦闘システムの試作版**です。
大きく作る前に、まず戦闘が面白いかどうかを遊んで確かめる段階です。
既存のゲーム(リポジトリ直下)には手を入れず、このディレクトリに新しい土台を作っています。

## 何が変わったか

旧版の戦闘は「1対1で技4つを選ぶだけ」で、相手の行動が読めないため、毎ターン同じ最適手を押す作業になっていました。
共鳴バトルでは、**毎ターン本当に迷う判断**が生まれるように組み直しました。

| 仕組み | 内容 | 判断が生まれる理由 |
|---|---|---|
| 予告 | 敵の次の行動・対象・予想ダメージを表示 | 危ない攻撃を先に止める/かばう/回復する、を選べる |
| タイムライン | 行動順を表示。重い技ほど次の番が遅れる | 強い技と手番の速さの取引 |
| ブレイク | 弱点で盾を割ると、予告取り消し・1手休み・被ダメ1.5倍 | 弱点探し → 集中攻撃のリズム。溜め中の大技も阻止できる |
| 鎮める | ブレイク中の野生を戦わずに帰す(守護獣はHP半分以下で) | 「支配しない」という作品のテーマを戦闘ルールで表現 |
| タイミング入力 | 攻撃時は威力、防御時はガード/パリィ | 手が止まらない。上手くなるほど強くなる(設定で自動化可) |
| 共鳴ゲージ・共鳴技 | 基本行動でためて、2〜3体の合体技で使う | ためるか、使うかの判断 |
| 場 | 戦場の属性。同属性の技が1.25倍。数手ごとに移り変わる | 場の予報を見て技を選ぶ、環術で塗り替える |
| 巡環士ユウ | プレイヤー自身が行動順に並ぶ(記録する/鎮める/はげます/環術/道具) | 主人公が戦闘に参加する |

## 遊び方

```bash
npm install
npm run dev        # 開発サーバー(http://localhost:5173)
npm run build      # dist/index.html(Phaser同梱・完全オフラインの単一HTML)
```

操作は、矢印キー/十字キー、Z/Enter(決定)、X/Esc(戻る)、タップ/クリックです。タイミング入力は Z・Space・タップで行います。
ゲームパッドにも対応しています。スマホは横向き推奨です(縦向きでも、操作パネルに全情報が出ます)。

## 構成

```
src/core/     戦闘ルール(描画に依存しない純TypeScript・決定論的)
  battle.ts   手番・ダメージ・ブレイク・鎮め・予告・場・共鳴技
  ai.ts       味方の自動方針(シミュレーション・おまかせ用)
  rules.ts    定数・計算式・乱数
src/data/     技・ユニット・遭遇・絵の対応表(データ駆動)
src/scenes/   Phaser 4 の戦闘シーン(演出・タイミング入力)
src/ui/       記録帳(操作パネル・DOM)と画面スタイル
src/audio/    動的BGM・効果音(Web Audio、外部ファイルなし)
src/art/      仮のモンスター絵・背景(手続き生成)
scripts/      バランスシミュレーション
tests/        単体テスト・バランス回帰テスト・E2E
```

- 戦闘ルールは描画から切り離してあり、乱数も固定できるため、同じ入力なら必ず同じ結果になります。
  これでテストとシミュレーションができます。
- UI は「戦場(Canvas)」と「記録帳(DOM)」の二層です。
  操作パネルは実寸で描くので、スマホでも文字が読め、ボタンは44px以上あります。

## 検証

```bash
npm run typecheck
npm test                      # 単体テスト + バランス回帰テスト
npm run sim -- 1000           # バランスシミュレーション(レポート)
npm run build && PW_CHROMIUM=/path/to/chrome npm run e2e   # 実ブラウザで3戦を最後まで遊ぶ
```

### バランス(AIに各1000戦ずつ戦わせた結果)

判断はAIが行い、入力の上手さを4段階に変えて測っています。

| 遭遇 | 不慣れ | 平均 | 上級 | 自動 |
|---|---|---|---|---|
| 森のざわめき(導入) | 100% | 100% | 100% | 100% |
| 灰星局の強制起動 | 82% | 98% | 100% | 92% |
| 森の守護獣 | 56% | 78% | 97% | 68% |

- 導入戦はほぼ負けませんが、仲間が倒れる場面もあります。
- 守護獣戦は腕前で勝率に大きな差が出ます。
- 設定の「自動」は、平均的な手動入力と大差がないように調整しています。

### 調整の記録

- **ダメージ式**:当初は `攻撃/(攻撃+防御)` でしたが、この式は値が飽和します。攻撃力を1.6倍にしても勝率が変わらなかったため、攻撃/防御の比に比例する式へ変更しました。
- **守護獣の速さ**:守護獣は仲間と同じ速さで、1戦に3回しか動けていませんでした。速さを上げて1周に2回ほど動くようにしました(行動順の表示にも2回並ぶので、予告として見えます)。
- **自動モード**:防御を常に成功扱いにすると、自動が平均的な手動より強くなり、入力する意味がなくなっていました。そこで自動の防御は成功率7割にしています。

## 素材(絵)の差し替え

`src/assets/user/` に、プロンプト集の名前で画像を置いてビルドすると、仮の絵の代わりに自動で使われます。
置いた分だけ差し替わります。詳細は `src/assets/user/README.md` を参照してください。

## まだやっていないこと

- フィールド移動、物語(ink)、育成は Phase 1 以降に作ります。
- 絵と音は仮です。BGMと効果音は数値検証済みですが、実際の聴き心地の確認はこれからです。
